Before you investigate

  • Run the API — Start the FastAPI server on port 8000 (see README). This page and OAuth live on the same host.
  • Authorize once — “Authorize Gmail” sends you through Google’s consent screen. We request read-only access so the tool can sync and index mail—not send mail on your behalf. If Google says the app is “being tested,” your Gmail must be added as a Test user in Google Cloud (OAuth consent screen) unless the app is published and verified—see the README.
  • Sync your index — After login, call POST /emails/sync (e.g. from README) so the database has messages to search.
  • Use the extension — Load the built dist/ folder in Chrome, then search from the toolbar popup while the API stays running.

OAuth tokens stay on this machine (token.json). Full setup is in the project README.
