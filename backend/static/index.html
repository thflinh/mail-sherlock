How it works

Three steps, then search.

STEP 01

Connect your inbox

Click "Authorize Gmail" and complete Google's read-only consent screen. Tokens stay on your machine.

STEP 02

Index your last N emails

Run POST /emails/sync once. mail-sherlock fetches and embeds up to 500 messages locally.

STEP 03

Setup

Before you investigate.

1. Run the API server
Start the FastAPI server on port 8000 (see README). This landing page, OAuth flow, and search all run on the same host — http://localhost:8000.
2. Authorize Gmail (read-only)
Click Authorize Gmail above. You'll go through Google's consent screen. The app requests read-only access only — it cannot send email. If Google says the app is "being tested," add your Gmail address as a Test user in Google Cloud Console.
3. Sync your index
After signing in, call POST /emails/sync once (e.g. curl -X POST http://localhost:8000/emails/sync). This fetches up to 500 messages, embeds them, and stores them in MongoDB.
4. (Optional) Install the Chrome extension
Load the built dist/ folder as an unpacked extension in Chrome. A panel will appear on the right edge of Gmail — drag it to reposition. Keep the API running while you browse.

FAQ

Common questions.

Why use localhost for sign-in, not 127.0.0.1?
Google's OAuth redirect URI must match exactly. The configured URI is http://localhost:8000/auth/callback. If you open the app via 127.0.0.1 the redirect won't match and sign-in will fail.
Does the extension send my mail to the cloud?
No. Search runs against your local API at http://127.0.0.1:8000. OAuth tokens are stored in token.json on disk. mail-sherlock has no hosted backend.
The extension says it can't reach the backend.
Keep the FastAPI process running on port 8000. The extension always calls http://127.0.0.1:8000. If you changed the port, update the extension's API URL and rebuild.
Do I need MongoDB?
Yes — emails and embeddings are stored there. Run it locally via Docker (docker run -p 27017:27017 mongo) or point MONGODB_URI at MongoDB Atlas. GET /health shows database status.
