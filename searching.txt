```
**Problem 2 — You're embedding subject + body as one flat string**

Right now your corpus text is probably:
```
"Lease extension confirmation Hi, we can extend the lease until June 2025..."
The subject carries 10x more signal than the body for search. Flattening them loses that weighting.
Fix — weight the subject:
python# embeddings.py — instead of flat concat
def make_corpus_text(email: dict) -> str:
    subject = email.get("subject", "")
    body    = (email.get("body") or "")[:500]
    # repeat subject 3x so embedding space tilts toward it
    return f"{subject}. {subject}. {subject}. {body}"

Problem 4 — No hybrid search (keyword fallback)
Semantic search fails on exact strings — order numbers, invoice IDs, names. If a user says "find INV-2024-0892", cosine similarity is useless.
Fix — add BM25 keyword search and merge scores:
python# pip install rank_bm25
from rank_bm25 import BM25Okapi

class HybridSearcher:
    def __init__(self, emails):
        self.emails = emails
        tokenized = [e["body"].lower().split() for e in emails]
        self.bm25 = BM25Okapi(tokenized)

    def search(self, query, semantic_scores, alpha=0.7):
        """
        alpha = weight for semantic score
        1-alpha = weight for BM25 keyword score
        """
        bm25_scores = self.bm25.get_scores(query.lower().split())

        # normalize both to 0-1
        sem_max  = max(semantic_scores) or 1
        bm25_max = max(bm25_scores) or 1

        combined = [
            alpha * (s / sem_max) + (1 - alpha) * (b / bm25_max)
            for s, b in zip(semantic_scores, bm25_scores)
        ]
        return combined
